# SwiftConvert – Currency Converter

SwiftConvert is a clean, fast, and responsive currency conversion web application that provides real-time exchange-rate conversion, 30-day historical trend visualization, favorite currency pairs, and a Travel Budgeting mode.

## Features

### Real-Time Currency Conversion

* Select a source currency and target currency.
* Enter an amount to get the converted value.
* Swap source and target currencies easily.
* Exchange rates are fetched through the ExchangeRate API.

### 30-Day Exchange Rate Trends

* Displays a line chart showing exchange-rate movement over the last 30 days.
* The chart updates based on the selected currency pair.
* Provides a visual way to understand recent exchange-rate trends.

### Favorites

* Save frequently used currency pairs.
* Quickly access saved currency pairs from the Favorites section.

### Travel Budgeting Mode

Travel Budgeting Mode allows users to enter an amount in a selected base currency and compare its equivalent value in five major currencies:

* USD – US Dollar
* EUR – Euro
* GBP – British Pound
* JPY – Japanese Yen
* AUD – Australian Dollar

The results are displayed together in a comparison table.

### Persistent Data

* Recent conversion history is stored for later access.
* User-defined favorite currency pairs are persisted.
* Data remains available when the application is reopened.

## Application Flow

### Normal Conversion

```text
User selects source and target currencies
              ↓
        Enters amount
              ↓
       Frontend sends request
              ↓
        Base44 Backend
              ↓
      ExchangeRate API
              ↓
      Exchange rate received
              ↓
       Conversion calculated
              ↓
      Result displayed
```

### Travel Budgeting Mode

```text
User enables Travel Mode
              ↓
     Selects base currency
              ↓
        Enters amount
              ↓
        Base44 Backend
              ↓
      Exchange-rate data
              ↓
   Calculate 5 currencies
              ↓
 USD | EUR | GBP | JPY | AUD
              ↓
     Comparison table
```

## Getting Started

1. Clone the repository.

```bash
git clone <your-github-repository-url>
```

2. Open the project directory.

```bash
cd swiftconvert-currency-converter
```

3. Configure the required ExchangeRate API credentials using environment variables.

4. Start the application using the project's configured development command.

5. Open the application in a browser.

## API Configuration

The ExchangeRate API key should be stored securely as a backend environment variable.

Do not commit API keys, passwords, tokens, or `.env` files to GitHub.

Example:

```text
EXCHANGE_RATE_API_KEY=your_api_key
```
